# 体验基线（重构前快照）

记录于 2026-07-07，基于 commit `78e9a8b`。本文档是"用户视角等价"的对照标准：重构后的应用在相同数据、相同操作下应与此处描述等价，除非某条被明确标记为"待修复缺陷"或"已批准变化"。

旧实现源码归档于 `legacy-backup/`（只读参考，其中 Tailwind 类名是视觉规格的权威来源）。

## 1. 页面与路由

- 单页应用，唯一路由 `/`，所有状态经查询参数表达。
- URL 参数契约：`y`（年份 `min-max`）、`s`（评分）、`r`（排名）、`v`（票数）、`e`（集数）、`t`（类型，逗号分隔）、`q`（搜索）、`st`（状态筛选）、`sort`（排序）、`p`（页码）。默认值不写入 URL；`?y=2022-2022&t=TV&q=bocchi&st=ignored&sort=date&p=3` 是合法分享链接。
- 详情弹窗不进 URL、不进历史（已知：手机按返回键会退出整站——待修复缺陷，批准改为返回键关闭弹窗）。

## 2. 首屏与加载

- 旧行为：黑屏 + 粉色 spinner + "Reloading Database..."，直到 10MB db.json 拉完。
- **已批准变化**：新版首屏为构建时静态渲染的默认视图（即时可见）；带筛选参数的分享链接先显示默认内容/骨架，索引就绪后切换为筛选结果。

## 3. 默认状态（信息等价的关键）

- 排序：Rank 升序（无排名条目排最后，同排名按评分降序 tie-break）。
- 类型：TV / Movie / OVA / Web 全选。
- 状态筛选：All；搜索：空；页码：1；每页 60 张卡。
- 筛选默认区间：year 0-2030、score 0-10、rank 0-99999、votes 0-999999、eps 0-9999。

## 4. 关键用户路径

1. **浏览**：卡片网格（2/3/4/5/6 列随断点）→ 分页（上一页/下一页/跳页，翻页平滑回顶）。
2. **筛选**：顶栏 FILTERS 按钮展开面板（桌面：下拉层；移动：全屏覆盖层）→ 预设 6 枚（Modern/Retro × Hits/Gems、Movie Hits/Gems，激活预设再点一次=还原默认）→ 五组数字区间（失焦或回车提交）→ 类型 toggle → 状态 tabs（Todo/Saved/Ignored/All）→ Max 52 Eps、>1 Ep 两个开关 → Clear Filters。
3. **季节**：年份 min=max 时出现季节选择器（Winter=1月起/Spring=4/Summer=7/Fall=10），再点取消。年份区间变化时季节自动清除。季节不进 URL（待决策：是否持久化）。
4. **搜索**：即时响应（无需回车），匹配标题/中文名/工作室/导演/脚本/精确 id。
5. **详情**：点卡片 → 弹窗（桌面居中大窗、移动全屏）：海报、评分分布图（桌面 only，hover 显票数）、社区统计、简介、Tags、Staff、外链（bangumi/bilibili 等）。关闭：X 按钮或点背景。
6. **管理员**：右下角锁图标（30% 透明度，hover 显形）→ 密码登录（邮箱隐藏在环境变量里）→ 卡片出现常驻三键操作栏（Ignore/Wishlist/Collect），详情弹窗出现大按钮 → 乐观更新 → Supabase 同步，失败回滚（已知缺陷：静默回滚，无任何提示——待修复，批准加 sonner toast）。
7. **游客视角收藏状态**：绿=已收藏、蓝=想看、红角标+灰阶+40% 透明=忽略。游客只读（详情内显示只读徽章）。

## 5. 视觉语言要点

- 深色主题：底色 neutral-950/黑，卡片 neutral-900，强调色 pink-500/600。
- 评分颜色分档（Bangumi 严格标准）：≥9 金 / ≥8.5 橙红 / ≥8 粉 / ≥7.5 绿 / ≥7 青 / ≥6 灰 / 其余暗灰。
- 排名徽章分档：≤100 金底 / ≤500 白底 / 其余半透明黑。
- 状态色语义：collected=green、wishlist=blue、ignored=red（角标）+灰阶。
- 字体：Geist Sans + Geist Mono（数字/代码感元素用 mono）。
- 细节：细滚动条、选中文本粉底白字、卡片 hover 图片轻微放大。

## 6. 已知缺陷清单（批准直接修复，记入 UX_CHANGELOG）

1. Episodes 手动筛选在默认状态下被 Movie 联动 effect 静默重置（联动规则本身待阶段 1 决策）。
2. 云同步失败静默回滚，无用户提示。
3. 收藏加载失败时 error 状态存在但 UI 从不展示。
4. 手机返回键关不掉详情弹窗，直接退出站点。
5. iOS 视口（vh vs dvh）与刘海屏安全区未处理。
6. 触控目标普遍小于 44px；数字输入未弹数字键盘。
7. 管理员视角"忽略卡片 hover 显形"在触屏上无等价物。
8. 页码越界（如筛选变化后 p 超出总页数）显示误导性的 "No results"。
9. realtime 订阅每次触发都全量重拉收藏表（低效但正确；顺手优化）。
10. 弹窗滚动锁手改 body style，iOS 有穿透风险。

## 7. 明确不做（记入未来建议）

- 详情页独立可分享 URL、虚拟滚动、底部抽屉式筛选、全面视觉改版。
