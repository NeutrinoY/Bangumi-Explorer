# UX_CHANGELOG · 2026-07 深度重构

记录本次重构中所有用户可见变化。分级：equivalent（不可感知）/ fix（缺陷修复）/ enhancement（体验增强）/ product-change（已获项目所有者批准的产品级变化）。

## product-change（均已事前批准）

| 位置 | 变化 | 说明 |
|---|---|---|
| 首屏 | 从"黑屏转圈等 10MB"改为构建时静态渲染的默认视图，即时可见 | 带筛选参数的分享链接会先显示默认静态视图，hydration 后恢复 URL 状态 |
| 状态筛选 tabs | 新增 Wishlist 选项 | 蓝色想看状态此前存在但无法单独筛选；URL 值 `st=wishlist` |
| 排序下拉 | 新增 Score 选项 | `?sort=score` 此前已是合法 URL，只是 UI 未露出 |
| 季节筛选 | 加入 URL 持久化（`sn` 参数） | 刷新/分享后季节选择不再丢失；旧链接不受影响 |
| Episodes×Movie 联动 | 改为"仅纯 Movie 视图禁用集数筛选" | 旧规则下默认全选状态集数筛选被静默重置（等于废的）；混合视图现在可用 |
| 详情弹窗 | 手机系统返回键现在关闭弹窗而非退出整站 | 桌面端同时支持 Escape 关闭 |

## fix

| 位置 | 修复 | 旧行为 |
|---|---|---|
| 收藏同步 | 失败时 toast 提示"已回滚" | 静默回滚，管理员不知道操作丢了 |
| 收藏加载 | 失败时 toast 提示 | 错误被吞，界面无反馈 |
| 分页 | 筛选收窄后页码自动收拢到有效范围 | 显示误导性的 "No results" |
| 状态筛选 Todo | wishlist 条目现在保留在 Todo 视图中 | 行为不变（旧逻辑一致），此处仅确认语义 |
| 移动端视口 | 全面改用 dvh + safe-area insets | iOS 地址栏伸缩导致内容被裁、按钮撞 home indicator |
| 触控目标 | 所有可点元素≥44px（图标不变，padding 补足） | 分页/排序/状态 tab 等触控区偏小 |
| 数字输入 | 弹出数字键盘（inputMode） | 手机上弹全键盘 |
| 忽略卡片（管理员） | hover 显形补充 focus-within 等价物 | 触屏设备永远看不清被忽略的卡片 |
| 搜索 URL 写入 | 防抖 300ms（筛选仍即时） | 每个按键触发 history.replaceState，Safari 有限流报错风险 |
| 重复数据 | ETL 按 id 去重 | 上游偶发重复条目（id 62893）产生重复卡片 |

## enhancement

| 位置 | 变化 |
|---|---|
| 状态 tabs / 季节按钮 | 移动端补充 title 提示（视觉不变，可猜性提升） |
| 详情弹窗 | 索引字段即时渲染，重字段（简介/评分分布/tags）异步补充，打开无阻塞 |
| 全站 | 控件补全 aria-label / aria-pressed / aria-expanded |
| 海报图片 | 加载完成淡入，替代"陆续 pop"的廉价感 |
| 结果集切换 | 翻页/换排序时网格轻量 fade（连续输入搜索则原地 reconcile，不闪） |
| 评分分布图 | 数据到达时柱子从底部生长到目标高度 |
| 卡片→详情 | 移除海报 morph，改为更克制的透明度/缩放入场，避免图片平移造成突兀感 |
| 移动端筛选面板 | 改为从底部 spring 滑入的 sheet（内容结构不变，仅动效方向），更贴合手势直觉 |
| 键盘焦点 | 全站统一 pink-500 focus-visible 焦点环 |
| 减弱动效 | 尊重 `prefers-reduced-motion`，系统开启时全站压缩动画时长 |

## equivalent（抽样）

- 视觉规格对照重构前 commit `78e9a8b` 重建：布局、配色、字体、间距、动效均保持。
- URL 参数契约完全兼容（y/s/r/v/e/t/q/st/sort/p），旧分享链接行为不变。
- 筛选、排序、预设匹配、季节窗口等业务规则逐条移植。
- 数据从单文件 db.json 拆分为 index.json + details-{0..7}.json（按 id 分 8 桶），字段值等价（快照对比验证，上游数据日常漂移除外）。索引加载后浏览器空闲时后台预取全部详情桶，逛几十秒后整库入内存，交互回到旧版"全量下载后"的零延迟。
